Noir AI Music Production Platform
==================================

Main Application:
URL: http://localhost:8080

Standalone Audio Tools (Work Independently):
============================================

1. Reverse Audio Tool:
   URL: http://localhost:8080/reverse-audio.html
   - Reverse audio playback

2. Speed/Tempo Audio Tool:
   URL: http://localhost:8080/speed-audio.html
   - Change speed (0.25x to 4x)
   - Custom speed multiplier input
   - Preset buttons for common speeds

3. Pitch Audio Tool:
   URL: http://localhost:8080/pitch-audio.html
   - Change pitch (-12 to +12 semitones)
   - Custom semitone input
   - Preset buttons for common intervals

Quick Start:
- Run: npm run dev
- Or use: ./start.sh

The server runs on port 8080.

Bookmark these URLs for quick access!
