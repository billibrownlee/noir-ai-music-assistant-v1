🎵 Noir Audio Tools

Standalone audio processing tools - Work independently

How to Use:

  1. Make sure Noir dev server is running (npm run dev)
  2. Click on any tool below to open it
  3. Upload your audio file
  4. Adjust settings and process
  5. Download the processed audio
🔄
Reverse Audio
Reverse audio playback direction. Perfect for creating reverse effects.
⚡
Speed/Tempo
Change audio speed from 0.25x to 4x. Custom input for precise control.
🎵
Pitch Shift
Change pitch from -12 to +12 semitones. Perfect for key changes.
